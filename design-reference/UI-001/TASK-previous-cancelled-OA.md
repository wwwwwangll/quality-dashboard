# 质见开发任务单

状态：已取消（模拟 OA 需求撤回，请停止相关开发）  
任务编号：OA-001  
目标：模拟 OA 报故单的「质量分析」节点，跳转至「质见」对应报故详情。

## 实现要求

- 在 quality-dashboard 下新增独立 oa-demo/，包含 OA 分区表格页面、本机启动脚本、同单号 CSV 导入样例及运行说明。页面标明「模拟 OA」，展示已到质量分析节点的合成报故单，覆盖申报信息、客户与产品、报故件明细、问题描述和处置方案。禁止复用截图中的人员、电话、客户或附件。
- 用现有 Node 运行时启动独立静态服务，绑定 127.0.0.1，默认 OA 端口 3881。启动参数指定质见测试站的回环 HTTP 地址，拒绝非回环地址、凭据、路径、查询、片段和相同端口。说明使用现有导入权限将样例通过报故导入预览、确认一次。合成单号固定为 OA-DEMO-001。
- 使用普通同标签页导航至质见 /#fault/ + encodeURIComponent(报故单号)，不把表单、账号或令牌带入 URL，不调用 OA 与质见之间的接口，不共享登录状态。对跨源导航设置 no-referrer。
- 复用质见现有登录和报故详情入口。登录成功后继续原片段。只从服务端已经授权的报故集合定位。缺失、无权限、非法编码或不合法单号统一提示「报故单不存在或无权查看」，清除旧详情并给出返回入口。只有具备报故列表访问权限才返回报故列表，否则返回有权限的工作台。不扩大读取或立项权限。
- 点击只导航，重复访问不创建报故或分析。范围仅限入口演示，旧索赔方案继续暂停，不实现 OA 审批分支和回传。
