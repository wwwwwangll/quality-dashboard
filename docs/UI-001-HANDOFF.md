- 索赔看板按 processingDate 优先、旧 date 兼容统计。索赔记录的处理日期不伪装成旧索赔日期；不合格单号独立于关联报故编号。

- 转嫁暂按「供应商承认金额」求和并在指标下注明；未知金额显示横杠和未填笔数。这是设计稿暂定口径，最终业务定义待确认。
